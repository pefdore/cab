🔐 Configuration Google Sheets OAuth

Étape 1: Créer un projet Google Cloud

  1. Allez sur Google Cloud Console
  2. Créez un nouveau projet (nom: "CotationCabinet")
  3. Attendez la création...

Étape 2: Activer l'API Google Sheets

  1. Dans le menu → "API et services" → "Bibliothèque"
  2. Rechezchez "Google Sheets API"
  3. Cliquez sur "Activer"

Étape 3: Créer les identifiants OAuth

  1. Aller dans "API et services" → "Identifiants"
  2. Cliquez "Créer des identifiants" → "ID client OAuth"
  3. Type d'application: "Application web"
  4. Nom: "CotationCabinet"
  5. URI de redirection autorisés: http://localhost
  6. Cliquez "Créer"
  7. Copiez le "Client ID" (ça ressemble à: xxx.apps.googleusercontent.com)
